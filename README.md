# PCNO-for-Advection-Diffusion-Equation
Use of Deep Learning based Surrogate Modeling technique (PCNO) to solve CFD fundamental equation i.e., 1D Advection Diffusion Equation
In order to use this code, you will have to save PCNO architecture build files and then try to run script file. Make sure you save PCNO files in appropriate directories defined in the code or change the code accordingly.
